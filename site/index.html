06 Persistência Especializada

Notação Comum.
Stores Contextuais.

Nem todo evento tem o mesmo objetivo. Em vez de um banco genérico com flags e exceções, cada categoria de fluxo possui uma store local especializada: eventos hiper-atômicos, comportamento do usuário, auto-cura ou provas formais.

QuarkBEQ.Store Entidade
Eventos hiper-atômicos por entidade com janela ativa curta e snapshots automáticos.

UserBehavior.Store Offline-First
Registra ações válidas, inválidas, comandos offline e correção contínua do usuário.

Carrega contraexemplos, traces, causas-raiz de falha e estratégias de reparação.
Chave: trace_id + counterexample

Persiste invariantes, evidências matemáticas e verificação estática com Haskell/Prolog.
Chave: lemma_hash + proof_state

08 Integração & CLI

Compilado em Zig. Executado em Qualquer Lugar.

Sem dependências externas, sem interpretador em runtime e sem alocações ocultas na heap. Clone o repositório e rode nativamente.

bash // zsh
$ git clone https://github.com/allascode/2flow.git
$ cd 2flow/repo
$ make test-all # Executa testes unitários e pipelines comptime
$ make wasm # Gera 2flow.wasm (2.7 KB) para validação client-side 2FV
$ zig build run_empresa
